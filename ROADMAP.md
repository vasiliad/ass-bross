# ROADMAP: ЭТАПЫ РАЗРАБОТКИ
**Проект:** Сверхлегкий веб-браузер (NanoWeb)
**Платформа:** Windows 10/11 x64
**Цель:** качественный сёрфинг по сайтам с содержимым в режиме чтения и максимально быстрый разбор страниц. JavaScript, аудио, видео и воспроизведение дизайна сайтов не поддерживаются (`ARCHITECTURE.md`, раздел 9).

Разработка разбита на изолированные инженерные вехи (Milestones). Каждая веха заканчивается проверяемым результатом и автоматическими тестами.

Порядок выбран так, чтобы движок не зависел от сети: этапы M1–M3 работают с локальными HTML-файлами. Сеть подключается, когда разбор и отображение уже стабильны.

**MVP = M0–M5.**

---

## Milestone 0: Инфраструктура
* Структура каталогов и сборка (`build.bat` для Windows, `Makefile` для сборки на Linux + запуск через Wine).
* `src/include/structs.inc` — определения всех структур из `MEMORY_MODEL.md` с проверкой размеров при сборке.
* Отладочный вывод: `dbg_print_str`, `dbg_print_int`, `dbg_print_hex` (stdout + `OutputDebugStringW`).
* Разбор аргументов командной строки (`GetCommandLineW`), чтение `nanoweb.ini`.
* Тестовый стенд: pytest запускает `nanoweb.exe` в режимах дампа и сравнивает вывод с эталонными файлами (golden tests).
* Бенчмарк-стенд: режим `--bench`, корпус сохранённых реальных страниц в `tests/bench/`, таблица результатов по коммитам.
* CI (GitHub Actions, `windows-latest`: сборка + тесты).
  * *Критерий приемки:* `nanoweb.exe --version` печатает версию; CI зелёный; тестовый стенд проходит пустой эталонный тест.

## Milestone 1: Память и быстрый разбор HTML
* **Арены:** `arena_init`, `arena_alloc`, `arena_append`, `arena_reset`, `arena_release`.
* **Загрузка файла** в `src_arena`; определение кодировки (UTF-8, windows-1251).
* **HTML Tokenizer:** возобновляемый конечный автомат (таблица переходов); SIMD-сканирование (SSE2, AVX2 по `CPUID`); числовые и основные именованные сущности.
* **Таблицы имён:** совершенный хэш для тегов и атрибутов, генерируемый при сборке.
* **DOM Builder:** дерево `DOM_NODE`, void-элементы, неявное закрытие тегов, восстановление после любых ошибок разметки.
* Режимы `--dump-dom <file>` и `--bench parse <file>`.
  * *Критерий приемки:* golden-тесты на корпусе реальных страниц из `tests/pages/`; разбор случайных и испорченных файлов не приводит к падению; **скорость HTML → DOM ≥ 200 МБ/с** на корпусе `tests/bench/`.

## Milestone 2: Режим чтения
* **Таблица ролей** тегов (`ARCHITECTURE.md`, раздел 6).
* **Hide Rules:** минимальный разбор CSS (`<style>`, `style=""`) — только `display: none` / `visibility: hidden`, простые селекторы, `@media`; атрибуты `hidden`, `aria-hidden`; корзины правил.
* **Измерение текста** через `SysFont` (GDI работает и без окна, через memory DC), кэш ширин символов.
* **Reader Layout:** колонка ~70 символов, абзацы, заголовки, списки с маркерами и номерами, цитаты, `pre`, таблицы построчно, `hr`, строчное оформление, перенос строк → массив `LINE` + `FRAGMENT`.
* **Картинки (раскладка):** запись `IMAGE` для каждого `<img>`, выбор источника (`src`/`data-src`/`srcset`), место по `width`/`height` или рамка с `alt`.
* Режимы `--dump-hidden`, `--dump-layout <file> [--width N]`, `--bench hide|layout`.
  * *Критерий приемки:* golden-тесты раскладки; на корпусе реальных страниц не видно типовых скрытых элементов (мобильные меню, cookie-баннеры, модальные окна) — проверяется списком ожидаемо скрытых элементов для каждой страницы.

## Milestone 3: Окно и отрисовка
* **SysGUI:** окно, DIB-буфер, system DPI aware, светлая/тёмная тема, цикл сообщений.
* **Painter:** текст, ссылки, маркеры, полосы цитат, линии; двоичный поиск видимых строк.
* **SysImage:** WIC — размер из заголовка, декодирование с уменьшением, кэш пикселей 6 МБ с вытеснением, альфа-смешивание SSE2. Локальные картинки рядом с HTML-файлом.
* **Прокрутка:** колесо мыши, клавиши (стрелки, PgUp/PgDn, Home/End, пробел), полоса прокрутки.
* **Resize:** пересчёт раскладки с сохранением верхней видимой строки.
* Открытие локального файла: `nanoweb.exe page.html`; режим `--stats`.
  * *Критерий приемки:* корпус страниц отображается корректно (скриншоты сверены вручную, затем фиксируются как эталоны); холодный старт < 20 мс; Private Bytes < 3 МБ без страницы; прокрутка 60 FPS.

## Milestone 4: Сеть (WinHTTP)
* **URL:** разбор, относительные ссылки, `file://`.
* **SysNet:** асинхронный WinHTTP с колбэком через `PostMessageW`; HTTPS, HTTP/2, распаковка gzip, редиректы, cookies сессии, системный прокси; заголовки как у обычного браузера.
* **Потоковый разбор** HTML по мере прихода данных.
* **Ресурсы:** внешние таблицы стилей (для Hide Rules, лимиты из раздела 7 архитектуры) и картинки (до 6 загрузок, видимые первыми).
* Встроенные страницы: нет соединения, ошибка HTTP, ошибка сертификата.
  * *Критерий приемки:* открываются http- и https-сайты из тестового набора; badssl.com (просроченный и самоподписанный сертификаты) даёт предупреждение; набор тестов против локального сервера (медленная отдача, обрыв, большие картинки) проходит; интерфейс не замирает во время загрузки; Private Bytes < 20 МБ на тестовом наборе с картинками.
  * *Проверка риска:* выдача DuckDuckGo Lite открывается без капчи. Если капча появляется регулярно — простые формы переносятся в MVP (`ARCHITECTURE.md`, раздел 11.1).

## Milestone 5: Навигация и поиск (завершение MVP)
* Адресная строка (стандартный `EDIT`-контрол Windows).
* Ссылки: клик, курсор-рука, строка состояния с адресом; переход к якорю `#id`.
* История: Назад/Вперёд (`Alt+←`/`Alt+→`, `Backspace`), обновление (`F5`). Заголовок окна из `<title>`.
* **Поиск из адресной строки:** шаблоны и префиксы из `nanoweb.ini` (DuckDuckGo Lite, `w` — Википедия); распознавание антибот-страниц и предложение другого поисковика.
* **Поиск по странице (Ctrl+F):** SIMD-поиск подстроки, без учёта регистра (латиница и кириллица), подсветка, F3 / Shift+F3.
  * *Критерий приемки:* по тестовому набору сайтов можно перемещаться по ссылкам и назад; запрос из адресной строки открывает выдачу поисковика; Ctrl+F на странице 1 МБ < 5 мс; все KPI из `ARCHITECTURE.md` (раздел 12) выполнены и зафиксированы в отчёте.

## После MVP (порядок предварительный)

### M6: Формы
* `<input>`, `<textarea>`, `<select>`, `<button>`; отправка `GET`/`POST` через WinHTTP — вход на форумы, поиск на сайтах без JS.

### M7: Marginalia
* Минимальный JSON-парсер; поиск Marginalia через API (префикс `m`), встроенная страница результатов, ключ из `nanoweb.ini`, обработка `503`.

### M8: История, закладки, вкладки
* История посещений и закладки, подсказки в адресной строке (SIMD-поиск подстроки); вкладки (отдельный набор арен на вкладку).

### M9: Улучшения отображения
* Настоящая сетка для таблиц с данными, анимация GIF, переключатель «скрыть навигацию» (`nav`, `aside`, `footer`), масштаб текста.
